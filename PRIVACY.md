# Privacy

Effective: September 26, 2026

Minecraft Skin Maker is an open-source skill and plugin maintained by Ömer Balkan ([BLCNYY](https://github.com/BLCNYY)).

## Images, prompts and output

Your agent reads the image, description or existing skin you provide. Its provider may process that input and generated previews under its own privacy policy and your account settings. Choose a host and settings appropriate for the files you share.

The bundled Python helpers read the specified local files and write skin textures, previews, editable designs, validation records and optional Bedrock packs to the chosen output directory. A reference review may copy your reference into that output directory. Delete these files through your normal file-management tools when you no longer need them.

The helpers contain no analytics, advertising, accounts, upload service or network requests. They do not send your references or skins to the project maintainer. Installing dependencies or downloading the plugin contacts the relevant package or source host. The host agent may use its own network tools; its activity is governed by that host and your permissions.

## Installation services and support

GitHub, agent providers, plugin directories and third-party installers have their own data practices. For example, the optional skills installer documents installation telemetry and an opt-out. These services are separate from the Python helpers.

GitHub issues are public. Share only prompts, previews and references that you intend to make public. The maintainer receives information you choose to post in an issue or another support request.

## Contact and changes

Contact the maintainer through [the repository](https://github.com/BLCNYY/minecraft-skin-maker/issues). Changes to this document are recorded in its Git history. This policy describes version 0.2.0 of the plugin.
